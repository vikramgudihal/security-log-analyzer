About the Security Log Analyzer

Security Operations & Threat Detection Project — Task 4

Project Objective

Task 4

This project was developed as a defensive cybersecurity tool for Task 4: Incident Response & Anomaly Detection.

The objective is to build a local, defensive security log analysis application that parses authentication logs (Linux auth.log / secure) and web server logs (Apache / Nginx), identifies repeated failed authentications, detects suspicious anomalies, classifies incident severities, and generates structured security reports.

Core Security Principles:

  • 100% Local Execution: Operates entirely offline with zero outbound network calls.
  • Non-Destructive: Performs strictly defensive analysis without executing uploaded files.
  • False-Positive Mitigation: Separates genuine user typos during work hours from high-volume automated brute-force attacks.

The 7 Implemented Detection Rules

Core Requirements
  1. Repeated Failed Authentication: Groups failed logins by source IP and flags threshold violations (1–3 LOW, 4–5 MEDIUM, >5 HIGH).
  2. Rapid Sequential Login Attempts: Sliding window detecting ≥4 failed attempts within 60 seconds.
  3. Multiple Usernames Targeted: Flags single IPs attempting multiple accounts (credential stuffing / user enumeration).
  4. Successful Login Following Repeated Failures: Detects when an IP successfully authenticates after ≥3 failed attempts (potential brute-force success / account takeover).
  5. Off-Hours Login Activity: Identifies logins outside configured business hours (08:00–18:00 Mon–Fri). Not classified as critical on its own.
  6. HTTP 401 & 403 Error Bursts: Identifies rapid access denial responses from web servers indicating directory/endpoint probing.
  7. Suspicious URL Signatures: Regex matching for SQL Injection, Path/Directory Traversal (`../etc/passwd`), and scanner agents.

Technology Stack

Specification

Backend:

  • Python 3: Core programming language
  • Flask 3.0: Lightweight, clean web framework
  • Regular Expressions (`re`): Custom log extraction & signature matching
  • Datetime: Timestamp normalization, rate limiting & off-hours calculation
  • Pandas: Data modeling & tabular structuring

Frontend & Testing:

  • HTML5 / CSS3: Clean, responsive user interface without sci-fi clutter
  • Chart.js 4: Interactive hourly authentication timeline and severity charts
  • Pytest: Automated unit & integration testing suite (22 tests passing)
  • Reports: Markdown (.md), Plaintext (.txt), and CSV (.csv) exports
